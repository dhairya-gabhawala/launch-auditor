Launch Auditor · How To

Step‑by‑step guide to running audits and interpreting results.

1) Run an Audit

  1. Open the app at http://localhost:4545.
  2. Click Run New Audit.
  3. Select a Site and Environment for a standard audit.
  4. Choose Manual URL if you want to compare specific containers.
  5. Click Run and wait for the loading indicator.

2) Compare Old vs New

Use comparison to highlight changes between two containers.

  • Always set the New environment to the container you want to review as the latest state.
  • Set Old environment to the baseline you are comparing against.
  • Use Manual URL for explicit comparisons and keep New = latest, Old = baseline.
  • The report will show deltas in the dashboard cards.
Swap new / old
Use Swap new/old if the comparison direction is reversed.

Understanding the Report

Dashboard Cards

Quick totals for data elements, rules, extensions, custom code actions, and RC files. Deltas appear only for comparisons.

Breakdown Tab

Grouped data elements and full rule details (events, conditions, actions) with formatted code blocks.

Opportunities Tab

Only shows recommendations (no duplicates) with line‑number hints and code context.

Manage Site Config

Use Manage Config to add sites and environment URLs. Changes persist to config.json in the project root.

{
  "sites": {
    "fishersci": {
      "environments": {
        "production": "https://assets.adobedtm.com/.../launch.js"
      }
    }
  }
}

Tips

  • Keep audit names consistent (e.g., 2026.02.05).
  • Use comparison before release to catch delta spikes.
  • Review Opportunities for custom‑code optimizations.
