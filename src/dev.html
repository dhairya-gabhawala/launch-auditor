Developer Guide

Architecture, data flow, and extension points.

Architecture

  • src/server.js — Express server, routes, UI shell
  • src/audit.js — container fetch, RC extraction, analysis
  • src/render.js — HTML report renderer
  • runs/ — generated reports by site + timestamp

Run Local

cd /path/to/launch-auditor
npm install
npm start

After npm install, the app auto-creates config.json from config.template.json if it doesn't already exist.

Data Flow

  1. Fetch container JS and extract RC URLs.
  2. Load container in VM and extract rules/data elements/extensions.
  3. Inspect custom code and generate findings.
  4. Render HTML report and store in runs/.

Extending Checks

Add/modify heuristics in analyzeCustomCode in src/audit.js.

Example: flag synchronous XHR, duplicate scripts, jQuery usage.

UI Notes

  • Reports open inside an iframe for quick navigation.
  • Client-side code formatting uses Prettier + Prism.
  • Sidebar supports search and delete.
